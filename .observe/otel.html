Audit notes

  • This repository is a Terraform Splunk Observability demo: collector agents, a gateway, optional Astronomy Shop, and one in-repo Python Lambda handler.
  • The Lambda already bootstraps Splunk APM traces through AWS_LAMBDA_EXEC_WRAPPER=/opt/otel-instrument, but OTEL_RESOURCE_ATTRIBUTES only sets a non-semconv environment= alias.
  • The handler reads ApproximateNumberOfMessages and writes SQS/DynamoDB outcomes with print(); it emits no app-owned queue-depth or consume/put metrics.
  • Host collectors and the gateway already export traces and metrics to Splunk Observability; nginx/apache/mysql metrics rely on collector discovery plus hostmetrics.
  • Astronomy Shop including product-reviews and llm is deployed from container images. GenAI spans, tokens, and workflow names are owned by those images, not this repo's application source.
  • Highest-priority app-owned work is Lambda resource identity, then SQS/DynamoDB worker metrics. Select those findings and run $otel-instrument.
